# 🏦 Bank Analytics & Credit/Debit Analysis Project

An end-to-end financial data analytics project exploring **Banking Operations** and **Credit & Debit Transaction Behaviour** using **SQL, Power BI, Tableau, and Microsoft Excel**.

---

## 📌 Project Overview

This repository contains two connected financial analytics modules designed to uncover actionable insights into loan performance, branch KPIs, transaction channels, and customer cash-flow patterns:

1. **Bank Analytics Module:** Focuses on overall banking metrics, loan distribution, customer demographics, and branch-level performance.
2. **Credit & Debit Analysis Module:** Examines transaction volumes, credit vs. debit inflows/outflows, payment methods, and high-value customer activity.
